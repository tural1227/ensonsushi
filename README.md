# 円村 · 鮨 ENSON SUSHI — Ginza Luxury Edomae Omakase

An avant-garde, immersive Japanese culinary sanctuary website crafted with authentic Wabi-Sabi aesthetics, kinetic storytelling, and cutting-edge web motion design.

---

## ✨ Features & Architecture

- **Cinema Canvas Frame Scroller Engine:** Ultra-smooth 60/120fps frame sequence scrubbing pinned on scroll with GSAP ScrollTrigger and Lenis.
- **Natural Rotating 3D Dining Table (職人の回転膳):** Interactive 3D isometric revolving counter with transparent Mino-yaki ceramic plates, drag-to-spin physics, dynamic flavor radar/sensory gauges, and live ingredient anatomy.
- **Wabi-Sabi Aesthetics & Handcrafted Details:** Sumi-e ink washes, Japanese washi paper grain, Asanoha lattice patterns, animated red Hanko seals, and subtle cultural motifs (Inari Kitsune, Sacred Pagoda, Mount Fuji).
- **Zen Ambient Sound Synthesizer:** Real-time micro-tuned Tibetan singing bowl acoustic harmonics created via Web Audio API.
- **Real-Time Tokyo (JST) Live Clock:** Dynamic Ginza time sync in navigation and fullscreen overlay.
- **Interactive Reservation Wizard & Cellar Dossier:** Complete choreographed multi-step booking experience.

---

## 🛠 Tech Stack

- **Frontend:** Semantic HTML5, Modular Modern CSS (CSS Variables, Flexbox, Grid, Washi textures)
- **Animation & Motion:** [GSAP 3.12](https://greensock.com/gsap/), [ScrollTrigger](https://greensock.com/scrolltrigger/), [Lenis Smooth Scroll](https://lenis.darkroom.engineering/)
- **Audio:** Web Audio API (Sine oscillators, exponential gain decay)
- **Icons:** [Lucide Icons](https://lucide.dev/)

---

## 🚀 Live Preview / Quick Start

Open `index.html` directly in your browser, or serve with any local HTTP server:

```bash
# Using VS Code Live Server, or Python:
python -m http.server 3000
```
Then visit `http://localhost:3000`.
